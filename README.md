# 📸 AllBoothNeng

A cutesy, web-based photobooth app built with 💖 — designed for fun photo sessions with countdowns, retakes, frames, and a sprinkle of floating doodles ✨

Live Demo 👉 [allboothneng.vercel.app](https://allboothneng.vercel.app/)

---

## 🌈 Features

- 📷 Take 4–6 photos with a configurable timer
- 🔁 Retake the last photo before confirming
- 🎨 Add cute, themed frames and overlays
- 💾 Automatically saves photo sessions
- ✨ Animated UI with playful transitions
- 🧚‍♀️ Floating decorations for a whimsical vibe
- 🖥️ Optimized for desktop/laptop usage

---

## 🚀 Tech Stack

- **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [ShadCN UI](https://ui.shadcn.dev/)
- **Routing**: [vite-plugin-pages](https://github.com/hannoeru/vite-plugin-pages)
- **State**: [Jotai](https://jotai.org/)
- **Animation**: [GSAP](https://greensock.com/gsap/)
- **Hosting**: [Vercel](https://vercel.com/)
